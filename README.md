🚗 RideGo — Online Ride Booking & Management System | C++

💡 A console-based ride booking system designed to simulate the core workflow of modern ride-hailing platforms.

✨ Key Features:
• 👤 Customer registration and information management
• 📍 Pickup and destination selection
• 🚘 Multiple ride types: Economy, Comfort & Premium
• 📏 Distance-based fare calculation
• 👨‍✈️ Available driver management and driver assignment
• ⭐ Driver ratings and vehicle information
• 💳 Multiple payment methods
• 🆔 Automatic Ride ID generation
• 📋 View current ride details
• ❌ Ride cancellation and driver availability management

🛠️ Skills Used:
C++ | Arrays | Functions | Loops | Conditions | Strings | Input Validation | Data Management | Business Logic | Problem Solving

🎯 This project helped me practice building a real-world management system using C++
